除了正在經營的 https://datafox.tw （歡迎大家繼續關注我的部落格！），我也開始更有意識地做一件事：
持續分享自己的觀察、學到的東西，還有那些一路上的迷路與修正。

我還記得正式構想我的podcast內容是交換接近尾聲，在聖托里尼島騎摩托車到oia的路上胡思亂想，想到一個還不錯的主題就隨便停在路邊記錄下來的。雖然2025年下半年因為碩士生活繁忙＋課程安排原因沒有認真參與到ntu podcast社團讓我有一點點的缺乏動力，但是自從我拿到了一筆不錯的獎學金之後，決定把這些獎學金的一部分拿來買podcast設備。而且當我想到我真的放棄的話我也可以把我買的機器賣掉，可以拿到大概7成的費用，就覺得這筆投資很划算。

我希望我可以留下legacy，除了我習慣的文字，我也希望用聲音來留下自己的足跡，讓大家可以用新的方式來理解我跟我身邊的優秀夥伴，和大家說說自己的故事。

對我來說，這不只是內容創作，而是一種「打造個人品牌」的過程。並不是要把自己包裝得多厲害，而是希望未來某一天，有人剛好在迷惘的時候，能看到這些紀錄，覺得——原來有人也這樣走過。

所以，我做了一個新的嘗試：
🎙️ Podcast《人生 Beta 版》!

這個節目會訪問 22–24 歲左右、剛走過大學或剛進職場的朋友，聊聊：當初以為的主線任務、那些誤打誤撞的支線，以及還有回頭看才懂的轉折，每一集，都會是一封寫給「迷茫版本自己」的錄音信。

如果你剛好也在探索人生、或只是想聽一些不那麼成功學的故事，歡迎成為早期聽眾（我會很感激你陪我一起 beta testing 🙏）

如果你：
- 覺得自己的人生有點混亂但其實蠻精彩
- 或者剛好走過一段值得回頭看的路

------
以下是nerdy的技術細節：

我的整體架構：
1. 贈三角架/線材/海綿/夾頭 Samson Q2U XLR USB 兩用 動圈式 麥克風 ATR2100X*2 $4100

2. 原廠 Focusrite Scarlett 2i2 3rd 第三代 錄音介面 solo $4790
3. 兩個有線耳機加上轉接頭當監聽
4. macbook air+Audacity

錄音 pipeline是：

```
聲音 → 麥克風(Q2U) → XLR → Scarlett 2i2 → ADC → Mac → Audacity → 檔案
```


---

# 🎤 1. 麥克風：Samson Q2U（Dynamic）

## 🔬 技術重點

* 類型：Dynamic (moving coil)
* 指向性：Cardioid
* 頻率響應：約 50Hz–15kHz
* 靈敏度：偏低（這是重點）

---

## ⚠️ 關鍵限制：輸出訊號很小
這會導致：

* 需要「高 gain」
* 但 gain 一高 → preamp noise 也上來

解決方法：
* 麥克風貼近（5–10 cm）
* gain 開在「合理範圍」（不是爆拉）

---

# 🎚️ 2. Scarlett 2i2 (3rd Gen)

## 🔬 規格關鍵

* Gain range：約 56 dB
* EIN（等效輸入噪音）：約 -128 dBu
* 24-bit / 192kHz

## ⚠️ 真實 bottleneck

Q2U + 2i2 會遇到一個典型問題：**要推很大 gain 才有聲音**


* hiss noise（底噪）
* 聲音不夠厚

🧠 進階優化（你之後可以考慮）

如果你未來想升級：

👉 加一個：

* Cloudlifter
* 或 FetHead

👉 作用：

* 提供 +20~25dB clean gain
* 降低 2i2 壓力

但現在：
👉 **你還不需要（真的）**

---

# 🔌 3. XLR vs USB（你做對一件事）

👉 你用 XLR → 2i2 → Mac

✔ 正確
✔ 可控
✔ latency 低

---

## ⚠️ 但注意一件事

👉 不要同時插 USB + XLR

（Q2U 支援雙模，但會搞混）

---

# 🎧 4. 監聽系統（你這邊有一點可以優化）

你現在：

👉 兩個有線耳機 + 轉接

---

## ⚠️ 問題點

* impedance 不匹配
* 音量可能不平均
* latency 或 phase 不一致

---

## 🧠 建議

👉 如果是雙人 podcast：

✔ 最好：

* 用 headphone splitter（有放大器的那種）

或

✔ 更進階：

* audio interface 有兩個 headphone out（你現在沒有）

---

# 💻 5. Audacity（軟體層）

## 🔬 建議設定

### 🎚️ Sample rate

👉 44.1kHz 或 48kHz（選一個固定）

👉 Podcast：

* 48kHz 比較常見

---

### 🎚️ Bit depth

👉 24-bit（錄音時）

👉 export：

* 16-bit 或 24-bit WAV / MP3

---

## 🎛️ Input level（超關鍵）

👉 目標：

* 平均：-18 ~ -12 dB
* 峰值：-6 dB 左右

👉 如果你 hitting 0：
= 你已經爆了（irreversible）

---

# 🎧 6. Latency / Monitoring

你現在可以用：

👉 Scarlett direct monitor（硬體監聽）

✔ 幾乎零延遲
✔ 比軟體好

👉 不要用 Audacity monitor（會 delay）

---

# 🔊 7. 真正影響最大的參數（排名）

我幫你排序（很重要）：

### 🥇 麥克風距離

→ 決定 50% 音質

### 🥈 房間反射

→ 決定 30%

### 🥉 Gain staging

→ 決定 15%

### 🪶 其他設備差異

→ 5%
