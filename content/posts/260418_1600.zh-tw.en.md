TITLE: Ask AI to Help Me Add a Navigation Search Bar
DESCRIPTION: Dive deep into how to implement an efficient navigation search bar on your Hugo website! This article details how the author integrated exact matching, date-based sorting, and a seamless interface by modifying hugo.yaml, index.json, and header.html, creating an in-site search function with a sophisticated design that significantly enhances the visitor's browsing experience.
BODY:

**Exact Match:** Unlike PaperMod's built-in fuzzy search (which often returns many irrelevant results), this search system enforces keyword matching. As long as the article title, summary, or content exactly contains the words you typed, it will be displayed immediately.
**Sorted by Time:** I added and enabled the date attribute in Hugo's data index (index.json) and forcibly set the "newest articles first" display order for search results on the frontend, also displaying the article's publication date.
**Seamless Interface Integration:** It is built within `layouts/partials/header.html` (meaning every page, such as post, portfolio, about, can directly access and use it), directly displaying results as an overlay, without jumping to a separate search page.

The specific changes I made include:

*   Added JSON to the Home output format in `hugo.yaml` (allowing Hugo to generate a search database when building the website).
*   Used a customized `layouts/_default/index.json` script to specifically fetch the time parameter, in addition to article titles and content.
*   Overwrote the theme's `layouts/partials/header.html` file, adding a purely frontend search bar design at the end (including a transparent background and a glowing border for a refined look).
You can directly return to your local preview or republish the webpage to test the search functionality! If you need to adjust the appearance or width, feel free to let me know anytime!
