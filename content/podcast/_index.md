# 人生 release note

人生 release note 是一個半訪談、半閒聊的頻道。  
datafox 目前是準 Google 實習生，但身邊有各式各樣走向不同道路的好朋友。  

這裡和「強者我朋友」那種已經很穩定、很強大的訪談不太一樣，我專門訪問那些還在探索、還在 debug、還在找下一個可能方向的人。  

我們想用現在的想法和聲音，為下一個 released version 蓋穩台階，也讓正在走相似道路的同儕與學弟妹，看見從大學畢業到進入職場這段時間，作為 beta 版的我們，下一個想嘗試的 branch。
