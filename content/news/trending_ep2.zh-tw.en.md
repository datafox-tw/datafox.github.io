## 4. [decolua/9router](https://github.com/decolua/9router)

> [→ GitHub Link](https://github.com/decolua/9router)

9Router is a free and efficient AI routing and token-saving tool, whose core value lies in helping developers address the high costs and usage limitations of AI model APIs. It can intelligently route mainstream AI coding tools like Claude Code, Cursor, and Copilot to over 40 providers and 100 models, featuring a smart three-tier fallback mechanism: prioritize subscriptions, then cheaper models, and finally free models, ensuring uninterrupted coding. Even more commendable is its "RTK token saving" feature, which automatically compresses tool outputs (e.g., Git diff), effectively saving 20-40% of input tokens. For engineers heavily reliant on AI for development, this is undoubtedly a cost-saving and hassle-free tool, ensuring you never have to worry about running out of tokens.

## 6. [rohitg00/agentmemory](https://github.com/rohitg00/agentmemory)

> [→ GitHub Link](https://github.com/rohitg00/agentmemory)

agentmemory is a pioneering AI coding agent persistent memory system, designed to solve the problem of AI agents being "forgetful" across sessions. It fundamentally eliminates the need for repeated explanations of project context or decisions by capturing every tool use by the agent, compressing it into searchable memories, and intelligently injecting relevant context at the start of the next session. Based on `iii-engine`, it combines hybrid search using BM25, vectors, and knowledge graphs, along with a unique four-layer memory integration mechanism (working, episodic, semantic, procedural), achieving excellent retrieval accuracy in industry benchmarks. agentmemory essentially provides AI agents with a reliable "brain," enabling them to accumulate experience and continuously learn, serving as a critical infrastructure for building smarter, more autonomous AI agents.

## 13. [VectifyAI/PageIndex](https://github.com/VectifyAI/PageIndex)

> [→ GitHub Link](https://github.com/VectifyAI/PageIndex)

PageIndex is a revolutionary "vector-less, inference-based" RAG (Retrieval Augmented Generation) system, designed for handling lengthy professional documents. It moves beyond the limitations of traditional vector databases and chunking, instead building a hierarchical tree-like index of documents and employing large language models for inference-based retrieval. This approach mimics how human experts understand complex documents through directories and structure, achieving more context-aware, explainable, and traceable retrieval, significantly improving accuracy in areas like financial reports (up to 98.7% on FinanceBench). PageIndex signals that RAG technology will evolve from mere semantic similarity to deeper logical reasoning, which is highly significant for enterprise applications requiring highly precise and reliable information retrieval.
